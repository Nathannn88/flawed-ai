# 庙宇供奉 MVP · 素材对接说明

> 给美术/建模队友的对接指南。当前 demo 是**纯代码占位**版本，本文说明「给什么格式 → 怎么替换进去」。

## 现状：目前 0 外部素材，全是代码占位
- 引擎：**Three.js**（网页 3D，浏览器直接跑）。
- 画面里的庙宇 / 神像 / 上贡者 / 宠物 / 供品 / 唱片**全部是代码生成的占位几何体**（方块、球、圆柱…），没用任何外部 3D 模型或贴图。
- 风格：卡通着色 + 描边，**最终的 cel-shaded 观感是代码里统一渲染的**——所以你们给的素材保持简单即可，不用自己烤光影/高光。
- 配色：去饱和东方治愈色盘（青绿 / 米褐 / 陶土橙 / 鼠尾草绿）。
- 音效：代码合成，无音频文件。

## 给我什么 → 我就能直接对接

### A. 3D 模型（人物 / 场景）——首选 **glTF / GLB**
- **格式**：`.glb`（Blender / C4D / Maya 都能导出），网页 3D 标准格式。
- **规格**：low-poly 低面数；真实比例（米）；**原点放脚底中心、面朝 +Z**；材质从简（我会统一套卡通着色，别做复杂 PBR）。
- **清单（按优先级）**：
  1. 人物：**神像**（诗人化身）、**宠物**（狗 + 面包机 + 唱片机三形态）、**上贡者**（村民 1~2 款）
  2. 场景：**庙宇本体**（长方体空间 + 可开合的门 + 屋顶）、地面 / 草坡
  3. 道具：**供品**（几款小物件）、**唱片**
- **命名**：`statue.glb` / `pet_dog.glb` / `pet_toaster.glb` / `pet_player.glb` / `villager.glb` / `temple.glb` / `offering_*.glb` / `record.glb`

### B. 2D 贴图 / 立绘 / UI——**PNG**
- 表面贴图**可无缝平铺**；立绘 / 图标用**透明底**；分辨率 1024² 或 2048²。
- 配色锚点（务必贴合，否则跟整体打架）：
  天空 `#7DB1AC` / 地面 `#C7B58D` / 屋顶 `#C06A3F` / 植被 `#7C9A5E` / 墙 `#9DA59B` / 描边 `#2E3A38`
- 命名对应用途：`ground.png` / `wall.png` / `roof.png` / `statue.png` / `offering.png` / `record.png`…

### C. 音频（可选）
- 背景音 / 音效：`.mp3` / `.ogg` / `.wav`，短循环即可。

## 一句话
**最容易直接对接的是 `.glb` 模型 + `.png` 贴图。** 先给「神像 + 宠物（狗/面包机/唱片机）+ 庙宇场景」这三样，我就能把占位替换成你们的美术。
