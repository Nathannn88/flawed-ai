# 庙宇供奉持续可玩原型 · 素材对接说明

> 给美术/建模队友的对接指南。当前 demo 是**纯代码占位**版本，本文说明「给什么格式 → 怎么替换进去」。

## 现状：目前 0 外部素材，全是代码占位
- 引擎：**Three.js**（网页 3D，浏览器直接跑）。
- 画面里的三房间庙宇 / 神像 / 三名房间管理员 / 夜间灵体 / 上供者 / 宠物 / 材料 / 五类记忆藏品**全部是代码生成的占位几何体**（方块、球、圆柱…），没用任何外部 3D 模型或贴图。
- 风格：卡通着色 + 描边，**最终的 cel-shaded 观感是代码里统一渲染的**——所以你们给的素材保持简单即可，不用自己烤光影/高光。
- 配色：去饱和东方治愈色盘（青绿 / 米褐 / 陶土橙 / 鼠尾草绿）。
- 音效：代码合成，无音频文件。

## 给我什么 → 我就能直接对接

### A. 3D 模型（人物 / 场景）——首选 **glTF / GLB**
- **格式**：`.glb`（Blender / C4D / Maya 都能导出），网页 3D 标准格式。
- **规格**：low-poly 低面数；真实比例（米）；**原点放脚底中心、面朝 +Z**；材质从简（我会统一套卡通着色，别做复杂 PBR）。
- **清单（按优先级）**：
  1. 人物：**神像**（诗人化身）、**夜间灵体**、**三名房间管理员**、**宠物**（狗 + 共鸣装置 + 唱片机三形态）、**上供者**（村民 1~2 款）
  2. 场景：**庙宇本体**（祈愿厅 + 处理室 + 陈列室 + 两段门洞／台阶 + 可开合庙门）、地面 / 草坡；空间关系以 `design/40-美术素材/场景素材/概念图/e3f12ba5116d8462683cee8321ed9665.jpg` 为布局参考，但运行时资产必须复制到本目录 `assets/`
  3. 道具：八种**供品材料**、无名记忆匣、万花筒果实、面包唱片、翻页种子书、榫卯月灯
- **命名**：`statue.glb` / `spirit.glb` / `manager_prayer.glb` / `manager_processing.glb` / `manager_gallery.glb` / `pet_dog.glb` / `pet_resonator.glb` / `pet_player.glb` / `villager.glb` / `temple_prayer.glb` / `temple_processing.glb` / `temple_gallery.glb` / `material_*.glb` / `carrier_memory_box.glb` / `relic_kaleidoscope_fruit.glb` / `relic_bread_record.glb` / `relic_seed_book.glb` / `relic_moon_lamp.glb`

### B. 2D 贴图 / 立绘 / UI——**PNG**
- 表面贴图**可无缝平铺**；立绘 / 图标用**透明底**；分辨率 1024² 或 2048²。
- 配色锚点（务必贴合，否则跟整体打架）：
  天空 `#7DB1AC` / 地面 `#C7B58D` / 屋顶 `#C06A3F` / 植被 `#7C9A5E` / 墙 `#9DA59B` / 描边 `#2E3A38`
- 命名对应用途：`ground.png` / `wall.png` / `roof.png` / `statue.png` / `material_*.png` / `carrier_*.png`…

### C. 音频（可选）
- 背景音 / 音效：`.mp3` / `.ogg` / `.wav`，短循环即可。

## 一句话
**最容易直接对接的是 `.glb` 模型 + `.png` 贴图。** 第一批优先给「三个房间壳体＋三名管理员＋独立灵体＋五类记忆藏品＋宠物三形态＋庙宇展示柜」，这样可同时验证空间移动、具身视角、收藏核心玩法和画风，而不是只替换背景场景。
