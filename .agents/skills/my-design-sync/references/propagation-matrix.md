# 传播对照表

> 这是快速提示，不替代根目录全文搜索、依赖通读和风险自适应验证。路径与依赖以 [`../config.json`](../config.json) 为准。

## 按输入类别

| 输入 | 默认落点 | 必查影响 |
|---|---|---|
| 项目目标、核心循环、设计护栏、统一术语 | `design/00-项目核心/` | 全部有效设计、PLAN、规则、法律企划书 |
| 玩法、资源、数值、付费、社群机制 | `design/10-玩法与系统/` | 世界剧情、角色、视觉、美术表现、最小切片 |
| 世界观、剧情、事件、岛屿 | `design/20-世界观与剧情/` | 角色、玩法、视觉、美术素材 |
| 诗人、宠物、上贡者、关系 | `design/30-角色设定/` | 世界剧情、玩法、角色素材、建模 |
| 图片、模型、PSD、场景、供品 | `design/40-美术素材/` | 素材索引、视觉规范、运行时副本 |
| 色彩、字体、构图、动效、设计 token | `design/50-视觉规范/` | 美术素材、代码 UI 与运行时资产 |
| 无法可靠分类的内容 | `design/90-待整理/` | 进度中的待确认事项 |
| 被新版本替代的旧件 | `design/99-待删除审核/` | 全仓旧引用、替代物、删除风险 |
| 合同、著作权、授权 | `法律文件/` | 来源索引、权利主体、派生格式 |
| 当前状态、决定、活动 | `记录/` | 进度与日志的职责分离 |

## 按操作

- **新增**：归类 → 定权威状态 → 建关联 → 更新索引与记录。
- **更新**：搜索实体与别名 → 修改所有有效位置 → 复核上下游。
- **替换**：新内容就位 → 引用重指 → 旧件进入待删除审核 → 扫描残留。
- **目录重构**：验证目标无冲突 → 迁移 → 修复全部路径依赖 → 删除空目录 → 再扫描。
- **导航／规则退役**：确认替代入口 → 删除获授权旧件 → 更新规则清单与历史边界 → 扫描活动残留；不从 Git、快照或审核区恢复 `.base`、MAP、子板块规则。
- **素材导入**：视觉检查 → 分类 → 保留源格式 → 更新素材索引；无法判断则待确认。

## 高频风险

### 权威变更

最高权威变更会使旧文稿反过来变成错误来源。必须全量复核，不用“兼容旧设定”的方式稀释新决策。

### 角色与关系

列出关系所有端点、别名和第三方叙事位置。角色图、模型和事件剧本可能同时受影响。

### 美术素材

设计源资产与运行时副本是两份不同职责的文件。源资产可重组；代码副本要稳定、优化并登记映射。

### 法律文件

产品设计可以为登记企划书提供内容，但法律文件仍单独管理。明确 Markdown 当前编辑源及 TXT/DOCX/PDF 派生关系，不让多个格式各自演变。
