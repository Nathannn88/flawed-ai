# Plan: 统一记忆藏品、甄选手势与双空间

**复杂度**：大（核心循环、概率规则、内容目录、可扩展背包、展示柜、四类 3D 奇珍与视觉验收）
**当前阶段**：修订契约待用户确认；确认前不修改实现代码或设计权威

## 框架重启

用户最新补充推翻了上一版“80% 通用载体只解锁艺术品、20% 独特结果才进入收藏系统”的双轨假设。新的统一对象是 **记忆藏品**：

```text
选择两件供品材料 + 消耗 1 点记忆能量
  → 合成与共鸣仪式
  → 80% 常规记忆藏品：通用载体外形 + 随机艺术品
  → 20% 配方奇珍：四岛专属外形 + 随机艺术品
  → 无倒计时地观看艺术品与 360°载体
  → 左拖「归还」：销毁本次藏品，返还原材料，不返还已经使用的记忆能量
  → 右拖「珍藏」：完整保存到记忆空间
  → 从记忆空间任选已珍藏物放入展示柜
```

80% 和 20% 的区别只在 **载体外形、来历与陈列稀有度**，不在“有没有艺术品、算不算藏品、能不能收藏”。所有共鸣结果都承载艺术品，所有被玩家留下的结果都是收藏品。

## 术语与空间职责

| 术语 | 定义 |
|---|---|
| 艺术品 | 一次共鸣唤起的艺术内容，可以是行为、建筑、音乐、图画、小说、设计／工艺等 |
| 记忆藏品 | 载体外形、内部艺术品、材料配方、岛屿来历、获得时间与玩家选择组成的统一对象 |
| 常规记忆藏品 | 80% 结果；采用可变色／纹理的通用载体，同样可收藏、查看和陈列 |
| 配方奇珍 | 命中四岛配方后的 20% 结果；采用专属 3D 外形，收藏和展示表现更独特 |
| 记忆空间 | 只在夜晚进入的可扩展背包，收纳全部被玩家“向右珍藏”的记忆藏品 |
| 展示柜 | 从记忆空间中挑选少数藏品公开陈列的策展空间；常规与奇珍均可入柜 |

艺术品不再脱离载体单独存成六张卡；“艺术内容”和“收藏物”在数据、交互和展示上始终绑定。

## 本轮结构性默认

1. **两件材料 + 一点能量共同完成一次仪式**。画面内部仍分“材料成形 → 能量共鸣 → 艺术显现”三个节拍，但资源在确认开始时原子校验，任一不足都不扣除。
2. **左拖按用户原意解释为不喜欢／不留下，右拖为喜欢／留下**。用户原句前半重复了“喜欢”，本计划按语义视为口误。
3. **左拖返还本次投入的两件原材料，不返还记忆能量**。材料回到可再组合状态；能量代表已经发生的注意与对话，若也返还会形成零成本反复重抽。
4. **右拖保存整个记忆藏品**，不是只保存艺术卡片；载体、艺术品、配方和来历之后仍可重新打开。
5. **常规与奇珍都能进入展示柜**。奇珍拥有独有 3D 模型和展签装饰，但不能垄断收藏资格。
6. **记忆空间逻辑容量不设上限**。界面按视口显示多格网格并分页／滚动扩展，不把首屏格数当成背包容量，也不引入付费扩容。
7. **左拖不是永久封禁艺术品**。它只销毁本次载体；该艺术品经过冷却后仍可能再次被回忆，避免玩家一次即时判断就永久失去内容。
8. UI 内保留 like／dislike 行为信号，但面向玩家使用“归还这段记忆／珍藏这段记忆”，避免把艺术欣赏表达成质量打分。

## 四岛配方奇珍

配方无顺序。命中配方后以 20% 概率得到对应奇珍，另外 80% 得到常规载体；未命中配方的材料组合稳定得到常规载体。

| 前四岛入口 | 材料配方（无顺序） | 20% 独特藏品 | 3D 设计与 360°观察重点 |
|---|---|---|---|
| 视觉 | `虹膜浆果 + 镜盐` | **万花筒果实** | 果实外壳像花瓣镜片，内部有三层错位色环；正面看色彩集中，侧面看镜片厚度，背面可见种蒂与结构接缝 |
| 表演 | `麦穗面包 + 回声贝` | **面包唱片** | 现有概念升级：烘烤纹路形成唱片沟槽，回声贝成为唱针；旋转时能看到面包厚度、焦边、贝壳唱臂和中心孔 |
| 文学 | `墨籽 + 线叶` | **翻页种子书** | 墨籽作为书脊核心，叶片像悬浮书页；侧面能看见页层，背面有根系缝线，自动慢转时书页轻微开合 |
| 设计与应用 | `榫木 + 釉土` | **榫卯月灯** | 无钉榫木框包住陶质月球灯胆；四面结构不同，背面显示插接关系，强调功能、材料和结构美 |

四件藏品使用同一去饱和东方 toon 色盘、反向壳墨线和软暖光，不引入写实 PBR 或外部素材。

## 常规载体与原型艺术品池

### 常规载体

- 名称：**无名记忆匣**
- 造型：同一基础 3D 结构根据艺术类型、材料组合和岛屿来历变化釉色、缝隙光、铭纹与展签。
- 状态：共鸣后与艺术品绑定为完整记忆藏品；它不是占位垃圾，而是可形成系列收藏的标准载体。
- 能力：与奇珍相同，支持珍藏、重开、360°观察和放入展示柜。

### 原型艺术品池

系统按任意数量设计；首轮放入 12 份明确标注为“原型虚构内容”的艺术记忆，用于验证多格背包、筛选、重复策略与详情表现，不把内容种子数误写成容量上限。

| 行为艺术 | 《为陌生人守一夜风》 |
| 建筑艺术 | 《会呼吸的潮汐图书馆》 |
| 建筑艺术 | 《只在雨中出现的剧场》 |
| 音乐 | 《七次退潮》 |

| 图画 | 《蓝色门后的午睡》 |

| 小说 | 《没有地图的第五座岛》 |

## 共鸣结果与左右拖

- 艺术品显现后不立即计时，玩家可以先阅读、聆听或观看，再旋转载体。
- 结果页同时展示艺术品内容、载体类型、材料来历和稀有外形。
- 左拖：销毁 `pendingResonanceResult`，返还原始两件材料，艺术品记为 `returned`。
- 右拖：生成稳定 `memoryItemId`，完整写入记忆空间，艺术品记为 `kept`。
- 手势提供等价按钮和键盘入口：左方向键／“归还材料”，右方向键／“珍藏记忆”；不使用 emoji 作为操作图标。
- 决定提交必须幂等：一次结果只能归还或珍藏一次，快速拖拽与按钮连击不能重复返料或重复入库。
- 奇珍使用专属完整模型；常规载体使用标准模型及材料／艺术类型变体，两者都支持拖拽 360°、缩放、自动慢转与重置。

## 夜间记忆空间：可扩展背包

- 入口只在 `NIGHT` 状态出现；进入白天时入口隐藏且已打开空间自动关闭。
- 内容区是密集但可读的多格背包，而不是六张固定卡和“安装装备”槽。
- 桌面首屏可见多行多列格位，移动端自适应减少列数；继续滚动／分页时动态生成格位，逻辑容量不限。
- 每格展示载体缩略图、艺术类型、标题、常规／奇珍标记、材料来历和是否在柜中。
- 支持按艺术类型、岛屿／配方、常规／奇珍、是否陈列筛选，并支持获得时间与标题排序。
- 点击格位打开统一详情和 360°检视；详情中可“放入展示柜／从柜中收回”。
- 空格只用于建立背包感，不代表锁定或付费容量。

## 展示柜：收藏后的策展层

- 展示柜不再是与记忆空间平行的第二套收藏数据库，只保存 `memoryItemId` 引用。
- 当前原型保留三槽作为策展选择；任意已珍藏藏品都可入柜，奇珍因专属外形更醒目。
- 同一件藏品不能占多个槽；替换前明确显示目标槽。
- 点击柜中藏品进入同一个 360°检视器，展签展示艺术品、载体、配方／材料与岛屿来历。
- 左拖未珍藏的即时结果不能直接入柜；先珍藏，再从记忆空间策展。

## Test-First 任务拆解

### M0：契约重校准

- **做什么**：确认左右方向、返料不返能量、所有藏品可陈列三个结构点；更新长任务契约、里程碑和验证映射。
- **验证**：CHARTER、PLAN、STATE 与用户确认内容逐项一致。

### M1：冻结内容目录与概率规则

- **RED 测试**：
  - 内容目录恰有前四岛、八种材料、四个无序配方、四件奇珍和至少 12 种艺术品；
  - 资源不足、重复选择或不存在 ID 时不消耗；
  - 成功一次消耗选中的两件材料与一点能量，不修改输入数组；
  - 命中配方时 `roll < 0.2` 产生奇珍，`roll === 0.2` 进入常规分支；
  - 未命中配方始终产生常规载体；
  - 两个概率分支都必须产生 `carrierType + artworkId`；
  - 未见池非空时优先新艺术品；
  - 左决策只返两件材料、不返能量；
  - 右决策只入库一次，同一结果重复 finalize 无效；
  - 柜位只引用已珍藏藏品且同一物不能重复占槽。
- **预期 RED**：缺少 `content-catalog.js`，以及 `game-rules.js` 没有新 API。
- **GREEN 验证**：`node --test prototype/temple-mvp/tests/content-catalog.test.cjs prototype/temple-mvp/tests/game-rules.test.cjs`

### M2：接入仪式与甄选状态机

- 供品按八种材料生成并在保管处显示岛屿／材料。
- 支持选择两件材料；一次仪式原子消耗两材料与一点能量。
- 画面表现“材料成形 → 能量共鸣 → 艺术显现”三个节拍，生成承载艺术品的常规或奇珍结果。
- 实现无倒计时观看、左右拖、按钮和键盘等价入口；常规与奇珍都能在决定前 360°观察。
- 删除旧“一件供品 + 一点能量直接生成唱片”的活动路径和提示。
- **验证**：规则测试、页面契约、内联脚本语法检查、真实浏览器两条分支。

### M3：实现可扩展记忆背包

- 创建只在夜晚可见的入口和动态多格网格。
- 实现筛选、排序、详情和多件状态，以至少 12 件测试数据验证非六卡布局；系统对更多项目继续扩展。
- 白天隐藏入口；跨到白天时强制关闭。
- **验证**：白天不可见／不可打开、夜晚空态、单件、12+ 多格、筛选与详情检视。

|---|---|---|
| 80% 再次被感知为安慰奖 | 中／高 | 两个分支都产出完整记忆藏品；奇珍只改变载体稀有外形 |

| 现有 1400 行单页继续膨胀 | 高／中 | 内容目录和纯规则移出；本轮不做高风险全量框架迁移 |
| 四件程序化模型辨识度不足 | 中／高 | 每件定义正／侧／背观察特征，真实截图逐件验收 |
| 概率分支难以稳定取得视觉证据 | 高／中 | 规则层注入 roll；页面提供仅用于验收的 URL 查询参数强制分支，不进入正常 UI |

| 浏览器控制仍不可用 | 中／高 | 自动证据继续推进；真实视觉保持 `BLOCKED`，不得以静态测试替代 |
