- 当前设计只从 `../../design/设计资料索引.md` 进入，并以 `../../design/00-项目核心/最高设计权威.md` 为最高权威。

- 活动规则不得扫描或加载本目录；本目录内不得创建名为 `AGENTS.md` 或 `CLAUDE.md` 的文件。
- 代码、构建、测试、Skill 活动输入和运行时资产不得依赖本目录。
- 如需评估历史复用价值，先在活动任务中说明具体文件、复用理由、适配成本和设计一致性；采用的内容必须复制到当前有效目录并按现行规则重新验收。
