## 📌 2026-06-09 · 团队会议(三段录音)

> ⭐ **核心决策来源。** 完整记录见 `Atlas/神像供奉游戏 - 设计讨论记录 2026-06-09.md`。

- 🔷 **`[决策]` 世界观** — 诗人传授智慧后乘船离开(未死)、精神存于纪念雕像;玩家 = 神像(诗人化身);白天石像实体收贡(开门)/ 夜晚灵体加工(关门)。**为什么**:比 v2「知识被窃 + 空白容器」更顺、更利于「被供奉快感」的玩法。
- 🔷 **`[决策]` 岛屿 4+1 结构** — 五门类(视觉 / 表演 / 文学 / 设计应用 / 媒体与综合),前 4 个来供奉,「媒体与综合」作为较现代门类不来供奉、前来捣乱,引出科技 / AI 故事线。
- 🔷 **`[决策]` 上贡者四级稀有度**(团队认为基本决定项目成败)— 不稀有 / 稀有 / 很稀有(约 10)/ 极其稀有(按岛对称约 4-5)。**为什么**:让「开门看谁来上贡」具备抽卡 / 收集吸引力。**原则**:避免阶级感、隐晦呈现、稀有角色带艺术隐喻、可为动物 / 吉祥物。
- 🔷 **`[决策]` 材料与成品双线收集** — 材料外观统一、光效区分稀有度;材料不必转化(可收藏);初版只做小麦。成品也分稀有度;极稀有角色产出须独一无二而非仅加工更快。
- 🔷 **`[决策]` 加工玩法** — 宠物 = 可变形加工机(面包机 / 唱片机,至少 4 岛各一种),夜晚出现、村民不可见;内置「有缺陷的 AI」做艺术教育(讲解 + 对话提信仰)。
- 🔷 **`[决策]` 进度防封顶**(趋于共识)— 弃「按稀有度堆进度」(会封顶导致流失),改**解锁式进度**:达成阶段解锁新角色、名气招来更稀有的人、出新角色须配套新艺术品。对话必须手动人为;信仰等级 2 后村民才供材料;以学换币;限刷(每天至少工作 5 分钟,想一直刷要付钱)。
- 🔷 **`[决策]` 三阶段规划** — ① 单机养成(当前核心)→ ② 社区型(玩家互访空间、社交化)→ ③ 世界观 + 故事线;可能额外做深度绑定的社交软件。**A 认为**最终做成社交媒体 / 社区潜力大于单纯一个游戏。
- 🔷 **`[决策]` 技术路线** — 先用 **3D 模型**试做最小 demo(2D/live2D 费人手,模型可复用),场景固定视角,先把「开门 → 白天 → 一圈人走过来」骨架实现给大家看。
