# 企鹅设定

> 从项目圣经 章三（企鹅部分）提取

---

## 基础设定

风格鲜明、可变形、审美象征、**燃料容器**。

---

## 变形形态

| 形态 | 描述 |
|------|------|
| 烤面包机 | 烤出一张 70 年代爵士专辑 |
| 闹钟 | 敲响抽象节奏 |
| 火箭背包 | — |
| 穿越器 | — |
| 超现实器具 | — |

---

## 角色弧线

- 前半段 → 趣味与审美装置
- 后半段 → 燃料与审美判断者
- **终局 → 变为船**

---

## 火种机制（成为诗人后）

企鹅不定期吐出审美碎片：

- 诗句
- 画面描述
- 抽象情绪
- 不完整隐喻

用户必须回应、转化。

> 我们不要求用户拥有完全能动性。因此：系统仍提供审美输入。
