# 系统机制

> 把世界观落成可玩的规则：核心循环、载体系统、能量、付费、社区。

---

## 职责范围

核心循环「**供奉 → 转化 → 再创作**」、多媒介载体系统（面包纹路=音乐 / 画布纹路=视觉 /
胶片=影像 / 手稿=文学）、智慧能量与审美能量、宠物变形加工机制、五种智慧分支的内容维度、
付费机制、阶段机制、社区互访机制。

> v1 仅有"面包纹路"单一载体，现已扩展为多媒介载体系统。

## 上游依赖

- `design/项目主旨.md` — 最高权威（核心循环、五种智慧、术语表）
- `design/story/世界观.md` — 三阶段结构与社区愿景的叙事意义
- `design/character/宠物设定.md` — 宠物在「转化」环节的角色（变形加工、能量载体）

## 下游影响

- *（未来 v3 编码阶段）* `project/src/lib/`、`src/types/`、`src/store/` —— 当前 v3 无代码

## 更新规则

改了系统规则后：
1. 数值常量（能量增减、稀有度、阈值）必须在文档中写清，作为未来代码的唯一来源
2. 检查「智慧能量 vs 审美能量」的关系是否仍与主旨术语表一致（此项为开放问题，见 `记录/进度.md`）
3. 与 `项目主旨.md` 核心循环核对一致
