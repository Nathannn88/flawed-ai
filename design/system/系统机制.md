# 系统机制

> 派生自 [[项目主旨]]
>
> **v3 更新（2026-06-10）**：按 06-09 团队讨论整合——昼夜循环、上贡者/材料/成品三层稀有度、信仰值进度、解锁式进度、限刷与付费、自动化托管、三阶段重排。

---

## 一、核心循环:昼夜结构

### 白天(开门)

- 村民走进庙来进贡、许愿、提问;玩家收下材料、**手动**对话作答;
- 基础时长约 **20 分钟**(数值待调),做收集、交谈;
- **最低在场**:每天白天至少"工作"5 分钟(期间无法行动,可挂机);之后可"跳舞"或**付钱直接跳舞**(限刷付费点);
- 点"关门/快进"进入夜晚。

### 夜晚(关门)

- 石像变诗人灵体,**宠物出现**(村民看不到宠物);
- **无时间概念**,玩家自由进出加工空间;
- 完成加工后开门回到白天。

### 托管与跳过(争议点,记录两种意见)

- **趋于共识(A 方案)**:跳过=交给**自动化进程/宠物托管**——玩家与村民时间不同流速;托管期仍有产出但**效率/稀有度降低**。总逻辑:**做得越少、回报越少**(区别于日活打卡型);
- **保留意见(B)**:逻辑仍别扭,建议先按白天/黑夜做出来,看到实际画面再优化;
- **初期落地**:**不做跳过功能**,改为宠物自动化("该做啥做啥");
- 已确定:白天=开门、黑夜=关门两个游戏状态;**命名与具体表现待定**。

## 二、初版加工链(最小骨架,必须先跑通)

```
白天:村民送来一捆小麦 → 收下存入存储空间
关门:石像变诗人,宠物出现
夜晚:诗人拿起小麦 → 宠物变形为面包机 → 放入加工
     → 自动产出成品(面包/唱片) → 宠物变形为唱片机 → 播放
     → 宠物 AI 讲解该作品
```

初版配置:**小麦 + 一种宠物形态 + 一个面包机 + 成品跑通程序**。团队自用、非交付,先搭骨架再加功能。

---

## 三、材料系统

- **外观统一、内涵区分**:所有岛带来的材料外形相同(如一捆小麦 icon 一致),**点开后通过背景/光效/文字标识**显示门类归属;
- **稀有度**:用白光/蓝光/金光等背景光区分;规划 **4–5 种稀有度**(避免"史诗/传说/神话"俗套命名);
- **与上贡者挂钩**:材料稀有度与上贡村民稀有度关联(见 [[上贡者设定]]);
- **材料 ≠ 必须转化**:珍贵材料可**保留不转化**("漂亮到不忍心加工")——**材料收集与成品收集两条线并存**,转不转化由玩家选择;
- **初版极简**:只做 1 种基础材料(**小麦**);后续用 AI 批量生成数百种现实材料再筛选扩充。

---

## 四、成品系统

- **成品稀有度**方案(待选其一或组合):
  - 同一作品分默认版/泛白光/泛金光/炫彩版;
  - 低级材料合成无装饰、高级材料带装饰;
  - 用"转化耗时""产出碎片"等体现品质;
- **独占产出**:极稀有角色的产出必须**独一无二**,而非仅"加工更快";
- 成品可陈列收藏,也可作为更高阶创作的二级材料(多媒介载体设定沿用:面包纹路=音乐/画布纹路=视觉/胶片=影像/手稿=文学)。

## 五、进度系统(信仰值与解锁式进度)

### 信仰值链条

```
村民许愿/提问(按玩家已获艺术品出题) → 玩家手动作答(知识输出)
  → 好感度/信仰值上升 → 村民达信仰等级 2 → 开始供奉材料
```

- **对话必须手动、人为**——宠物只负责材料处理;玩家不做"智慧化身"与村民交流,**庙的进度条变慢**,长期停留第一阶段,拿不到稀有的东西。

### 解锁式进度(防"集齐即弃"悖论)

- **悖论**:按稀有度堆进度有封顶——玩家集齐最稀有的就停玩(类似集换式卡牌);
- **解法**:进度=**解锁新角色**——产出特定/一定量艺术品 → 名气达标 → 更稀有的人前来("想看看你到底怎么回事");出新角色配套新艺术品,集齐后角色到来;
- **价值体系演化**:开始产出稀有物后,低级材料自然贬值("刷不刷无所谓"),无须强制淘汰。

### 教育输出机制

- 教育不能只输入,**必须有输出**且融入游戏步骤:村民提问→玩家作答;
- **以学换币**:玩家通过学习内容获得代币;
- 交互中必须存在"知识",才能提高信仰值。

## 六、付费机制

| 付费点 | 说明 |
|--------|------|
| 付钱跳舞 | 白天 5 分钟最低工作后,持续刷需持续付费(限刷机制) |
| 主题皮肤 | 黑夜模式可切换主题(圣诞、冬/夏季等),避免场景看腻,作为充值动态 |
| 赛季角色/内容 | 极稀有角色按版本/赛季推出,配套新艺术品 |
| 收集类充值系统 | 与解锁式进度配合(具体方案待细化) |

**沿用红线**(v2 确立,继续有效):付费不可直接购买审美成长本身;不可付费绕过艺术理解过程。
⚠️ [[盈利模式-正式版]] 基于 v2 叙事,需按 v3 复核(如"庙宇皮肤"→"主题皮肤"已部分吻合)。

## 七、三阶段规划

| 阶段 | 形态 | 内容 |
|------|------|------|
| **一** | 单机养成 | 庙宇供奉+加工产出核心;验证盈利能力;生长期内容(开服半年量级),初期 1–2 个版本,后续靠道具/人物更新填充 |
| **二** | 社区型 | 玩家互访空间、装饰游戏化(类似 QQ 空间);可考虑配套深度绑定的社交软件(公会式,达级解锁);v2 艺术漂流机制保留备用 |
| **三** | 世界观+故事线 | 完整叙事(诗人去向、五子、媒体与综合捣乱线)放最后 |

## 八、实现优先级(美术/内容)

1. **诗人**(两套形态:白天石像/夜晚灵体)与**宠物**的形象;
2. **岛民**(稀有/不稀有)形象 + 四岛**符号**;
3. **道具/材料**(含转化器、转化前后形态、成品形态)——先做小麦;
4. **场景**(白天/夜晚两套;宠物白天不出现)——优先级最低,但要考虑 UI 界面功能;场景视线固定不动,村民走进来,基本一个场景。

技术路线:先做**能运行的最小 demo**(网上找素材占位,3D 模型试做),跑通"白天收小麦→夜晚宠物变面包机加工→产出唱片→AI 讲解"全流程,再逐步加功能。**实现部分由用户(A)负责。**

- 昼夜跳过/托管的最终形态(A 方案 vs B 保留意见);
- 白天/黑夜状态正式命名;
- "媒体与综合捣乱"线(科技 AI 对抗、鉴别 AI 艺术玩法)与主玩法的整合;
- 成品稀有度方案三选一(或组合);
- 白天基础时长 20 分钟等数值待实测调整。
