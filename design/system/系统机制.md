## 一、产品流程

### 1. 引导关卡：诗人之像的苏醒

庙内全景 → 第一次供奉（如黄金小麦）→ 智慧能量首次积累 → 宠物苏醒 → 宠物变形加工 → 第一件艺术产物陈列

### 2. 第一阶段：庙宇苏醒期

供奉循环 + 宠物变形加工 + 五分支探索 + 智慧能量积累 + 萨满的五个孩子互动

### 3. 阶段转变：艺术漂流激活

庙宇达到综合指标 → 对外感应能力觉醒 → 宠物获得离庙探访能力

### 4. 第二阶段：艺术漂流期

庙内创作持续 + 宠物探访他人庙宇 + 留痕 / 赠礼 / 协作加工 + 漂流网络节点成长

### 5. 第三阶段（后续版本）：真实历史解构

历史碎片浮现 → 庙内拼合 → 叙事解锁 → 认识诗人真相

## 二、能量系统

### 1. 智慧能量（玩家苏醒进度）

- **性质**：玩家（诗人之像）苏醒进度的度量
- **积累**：每次成功的创作循环都会积累
- **作用**：宏观进程推进资源
  - 解锁新的加工形态
  - 推动阶段转变触发
  - 影响庙宇视觉苏醒度

### 2. 审美能量（创作过程原料）

- **性质**：加工过程中的基础能量原料
- **来源**：部分作为供品直接到达；部分由玩家完成特定循环后生成
- **作用**：微观创作资源，被具体加工活动消耗

> **待用户确认**：智慧能量 vs 审美能量的关系 —— 当前以"两个层级"区分。若用户定案为同一概念，需合并术语。

### 3. 能量的非交易性

**红线**：任何付费机制都**不能直接提升**玩家的智慧能量，也不能绕过艺术理解过程。付费只能作用于：

- 外观装饰
- 流程便利
- 内容扩展

## 三、供奉系统

### 供品类型

| 类型 | 示例 |
|------|------|
| 作物 | 黄金小麦、稻田、棉花 |
| 矿物 | 特殊矿石、颜料原石 |
| 情绪碎片 | 抽象化的情感素材 |
| 审美能量 | 抽象基础能量原料 |

### 供奉者

- **普通岛民**：按周期自然到达
- **特殊角色**：萨满的五个孩子、隐居者等（带独特属性的供品）
- **其他玩家**（后期）：通过艺术漂流赠礼

### 供奉节奏

- 默认每 2–4 小时产生一次新供品
- 供品积累本身是天然的节奏墙（非传统体力系统）

## 四、多媒介载体系统

游戏不直接呈现现实艺术作品，而是通过**隐喻化载体**转译。

### 核心概念

- 艺术信息以**多种载体纹路**存在（面包纹路 / 画布纹路 / 胶片 / 手稿等），对应不同智慧分支
- 玩家收集素材 + 宠物变形为加工装置 → "烘焙" / "绘制" / "放映" / "书写"
- 产物通过"播放" / "展示"转化为感知体验

### 设计意图

- 避免直接收集艺术品的枯燥感
- 强化探索与理解的参与感
- 将艺术编码为可操作媒介

### 示例（intro 原例）

黄金小麦 + 审美能量 → 唱片面包 → 宠物变形为烘焙装置加工 → 玩家选择风格方向 → 随机生成的一段音轨 / 唱片

> 待扩展：各载体纹路的具体设计、加工规则、播放/展示效果

## 五、核心循环：供奉 → 转化 → 再创作

### 1. 供奉

玩家在庙中接收供品（见第三节）。

### 2. 转化

玩家指挥宠物变形为对应加工装置，将原材料加工为艺术产物。

加工过程中：
- 玩家选择**风格方向**（决定结果的美学倾向）
- 投入相应**审美能量**
- 可选投入**创作催化剂**（奇异碎片）以扩展变体 / 触发特殊效果

### 3. 再创作

艺术产物的处理方式：
- 陈列于庙中（积累智慧能量，影响庙宇苏醒度）
- 作为二级材料参与更高阶的组合与加工
- 赠予其他玩家（漂流阶段）

## 六、付费机制

### 原则

**付费不可购买审美成长本身。**

### 允许的付费点

- 宠物变形形态外观皮肤
- 庙宇 / 诗人之像 / 陈列家具外观
- 加速供品收取频率（不改变加工过程）
- 稀有供品概率提升（仅影响外观/叙事，不影响数值）
- 创作催化剂（加速变体尝试，不绕过理解）
- 艺术品图鉴深度扩展（真实艺术史内容包）
- 宠物 AI 深度解析（基础免费 + 深度付费）
- 艺术主题赛季限定皮肤 / 内容包

### 禁止的付费点

- 直接购买智慧能量
- 付费解锁艺术媒介的基础访问
- 付费绕过探访冷却 / 阶段转变门槛
- 付费获得他人作品的再加工协作权

## 七、内容生态

### 玩家贡献

- 玩家可通过投稿、创作进入系统内容池
- 系统筛选、整合、再传播
- 优质内容可能被选入庙宇装修 / 漂流可遇素材

### 生态循环

玩家创作 → 系统筛选 → 编码为多媒介载体 → 其他玩家在漂流中遇到 → 新的创作灵感

## 八、社区机制：艺术漂流网络

### 阶段转变触发后

庙宇具备**对外感应能力**，玩家可派遣宠物前往其他玩家的庙宇探访。

### 宠物的双重角色

- **信使**：带回他人庙宇的艺术片段、风格印记、创作倾向
- **感知媒介**：留下留言 / 赠予艺术品 / 参与对方未完成作品的再加工

### 非实时低干扰

- 所有交互异步完成
- 不存在即时聊天 / 实时互动
- 接收方在自己节奏中查看留痕

### 协作与再加工

- 玩家可开放自己的"未完成作品"供他人宠物协作加工
- 系统审核机制确保内容围绕艺术表达

### 作品演化

作品在庙宇间流转、被再解释、再加工，形成独特演化路径。**玩家既是创作者，也是他人创作链条中的一环。**

## 九、阶段差异

| 指标 | 庙宇苏醒期 | 艺术漂流期 | 真实历史期 |
|------|------------|------------|------------|
| 核心循环 | 供奉—转化—再创作 | 漂流 + 协作加工 | 历史碎片拼合 |
| 智慧能量 | 线性积累 | 持续循环 | 受真相进展影响 |
| 庙宇规模 | 个人 | 漂流节点 | 叙事地标 |
| 主要乐趣 | 审美探索 | 共创 / 启发 | 叙事解构 |
